第 1 章 · 概览

🧭课程概览

AI 不会取代艺术家，但会用 AI 的艺术家正在取代不会用的。本课程的目标是让每位同事都能把多种 AI 模型当作"协作工具链"来使用，而不是单点工具。

艺术创作不是"输入一句话出一张图"那么简单。一个成熟的 AI 创作流程，通常会让不同类型的模型各司其职：

🧠

推理 / 文本模型

负责"想"

创意发散、概念设定、世界观构建、脚本与分镜、提示词撰写与优化。是整个流程的"大脑"。

🖼️

图像模型

负责"画"

概念图、角色设定、场景插画、海报、材质贴图。从草稿到成品的视觉主力。

🎬

视频模型

负责"动"

动态分镜、短片、广告、概念预告。把静态创意变成有时间维度的影像。

🤖

Agent

负责"串"

把多个模型与工具自动编排起来，处理批量任务、调用工具、执行多步骤工作流。

💡 核心理念
把每个模型理解为团队里不同工种的"同事"：推理模型是创意总监，图像模型是美术，视频模型是导演，Agent 是制片助理。你的角色是艺术指导（Art Director）——定方向、提要求、做取舍。
第 2 章 · 流程

🔄标准创作流程

推荐的五阶段流程，适用于绝大多数艺术创作项目（插画、概念设计、短片、品牌视觉等）。

STEP 1

构思 / Ideation

用推理模型发散创意、确定风格与世界观。

STEP 2

提示词工程

把创意翻译成结构化、可复用的提示词。

STEP 3

图像生成

出概念图、设定图，反复迭代锁定视觉。

STEP 4

动态化

用视频模型让关键画面动起来。

STEP 5

合成 / 交付

后期剪辑、调色、放大、Agent 批处理。

每个阶段该用哪类模型？

阶段主要任务推荐模型类别典型工具
1. 构思头脑风暴、风格定位、剧本/分镜推理 / 文本模型GPT-5、Claude Opus 4.x、Gemini
2. 提示词结构化提示、多语言、风格关键词推理模型 + 提示词库Claude、GPT，配合参考图
3. 图像概念图、设定、海报、贴图图像模型Midjourney、Flux、Nano Banana、SD
4. 视频动态镜头、转场、短片视频模型Sora、Veo、Runway、Kling
5. 交付放大、调色、批量、合成Agent + 专用工具ComfyUI、Topaz、剪辑软件
🔁 关键：迭代而非一次成型
真正的产出质量来自循环——生成 → 评估 → 调整提示词 → 再生成。把前一轮的结果（图/帧）作为下一轮的参考输入（图生图、首尾帧），是专业流程与业余流程最大的差别。
第 3 章 · 模型

🧠推理 / 文本模型

在艺术创作中，文本/推理模型并不直接出图，但它决定了你的创意上限。它负责：创意发散、世界观、剧本、分镜、以及最关键的——把模糊想法翻译成精确提示词。

🟢

OpenAI GPT-5 / o 系列

通用 + 深度推理

综合能力强，多模态（可读图），适合创意发散、剧本写作、提示词生成。o 系列推理模型擅长复杂的多步骤构思。

创意发散读图剧本
🟣

Anthropic Claude Opus 4.x

长文本 + 结构化

长上下文、文风细腻、结构化输出稳定，特别适合撰写复杂提示词模板、世界观设定文档、严谨的分镜脚本。

提示词工程世界观长文档
🔵

Google Gemini

原生多模态

原生多模态、超长上下文，能同时处理大量参考图与文本，适合做风格分析和视觉参考整理。

多模态风格分析
⚫

DeepSeek-R1 / 其他开源

可私有部署

开源推理模型，可本地/私有部署，适合对数据保密有要求或需要大批量低成本调用的场景。

私有部署低成本

在创作中怎么用？三个高频场景

  1. 创意发散："我想做一个赛博朋克 + 敦煌壁画融合的系列插画，给我 10 个差异化的视觉方向，每个附一句话氛围描述。"
  2. 提示词生成：把模糊想法交给模型，让它产出结构化、可直接喂给 Midjourney/Flux 的英文提示词。
  3. 分镜脚本："把这个 30 秒广告拆成 6 个镜头，每个镜头给出画面描述、镜头运动、时长。"
让推理模型当"提示词工程师"
角色：你是资深 AI 艺术提示词工程师。
任务：把我的创意转成 Midjourney v7 英文提示词。
我的创意：一只穿宇航服的猫，孤独地站在火星沙丘上看地球升起，电影感。
输出要求：
1. 主体 + 环境 + 光线 + 镜头 + 风格，逗号分隔
2. 给出 3 个风格变体（写实/插画/极简）
3. 附 --ar 16:9 等参数建议
💡 实操技巧
让推理模型生成提示词时，明确告诉它目标模型（Midjourney / Flux / Sora 的提示词语法差异很大）。并要求它输出英文——绝大多数图像/视频模型对英文提示词的理解优于中文。
第 4 章 · 模型

🖼️图像生成模型

图像模型是艺术创作的视觉主力。不同模型在"美学风格、可控性、文字渲染、本地部署"上各有所长，需要按任务选型。

🎨

Midjourney v7

美学天花板

默认出图美感极强，适合概念图、海报、氛围图。风格化、光影、构图开箱即用。可控性中等，需配合 sref/cref 等参数。

美学概念图海报
⚡

Flux (Black Forest Labs)

质量 + 可控

开源/商用兼具，提示词遵循度高、文字渲染好，可本地部署并训练 LoRA。专业可控流程的首选之一。

可控文字渲染可微调
🍌

Gemini 图像 (Nano Banana)

对话式编辑

Google 的图像生成/编辑模型，强项是自然语言局部修改与多图融合——"把背景换成黄昏""保持人物不变换个姿势"非常顺手。

局部编辑多图融合
🟢

GPT 图像生成 (DALL·E 系)

对话 + 理解力

与对话深度结合，能理解复杂语义和构图指令，文字渲染好。适合需要"边聊边改"和强语义的场景。

语义强文字易用
🧩

Stable Diffusion / SDXL

开源生态王

开源、可完全本地部署，配合 ComfyUI、ControlNet、LoRA 实现像素级可控。生态最丰富，是专业可控流程的基石。

完全可控本地ControlNet
✒️

Ideogram / Recraft

文字 + 设计

在文字渲染、Logo、矢量、平面设计类任务上表现突出，适合需要排版和品牌元素的商业设计。

文字排版Logo矢量

关键能力对比

模型开箱美学可控性文字渲染本地部署最适合
Midjourney v7极高中中否概念图 / 海报 / 氛围
Flux高高好是专业可控 / 商用
Nano Banana高高好否局部编辑 / 改图
SD / SDXL中极高中是像素级可控流程
Ideogram高中极好否文字 / Logo / 平面
🎯 选型口诀
要美感、出概念 → Midjourney；要可控、要商用、要微调 → Flux / SD；要改图、局部编辑 → Nano Banana / GPT 图像；要文字和排版 → Ideogram / Recraft。

图像提示词结构（通用公式）

通用图像提示词模板
[主体] + [动作/姿态] + [环境/背景] +
[光线] + [镜头/视角] + [风格/艺术家参考] +
[画质词] + [参数 --ar --style 等]

示例：
A lone astronaut cat, standing on a red Mars dune,
looking at Earth rising on the horizon,
golden hour rim light, cinematic wide shot,
in the style of Studio Ghibli concept art,
highly detailed, 8k --ar 16:9 --style raw
第 5 章 · 模型

🎬视频生成模型

视频模型把静态创意变成有时间维度的影像。核心玩法有三种：文生视频、图生视频（让一张图动起来）、首尾帧控制。

🟢

OpenAI Sora

叙事 + 物理

长时长、镜头连贯性与物理真实感强，适合有叙事的短片、复杂运动场景。支持图生视频与混剪。

叙事短片物理真实
🔵

Google Veo

画质 + 原生音频

电影级画质，可原生生成同步音效与对白，提示词遵循度高。适合广告级、写实向成片。

原生音频电影画质
🟠

Runway Gen-4

创作者工具链

面向专业创作者，工具最全：运动笔刷、相机控制、角色一致性、视频编辑。适合精细化可控创作。

精细控制角色一致
🔴

快手 Kling / 可灵

国产强者

运动幅度大、人物表现好，首尾帧控制实用，性价比高。中文场景与本地化需求友好。

首尾帧性价比
🟣

Pika / Luma / Hailuo

轻量快速

生成快、易上手，适合快速出概念动态、社媒短内容、创意验证。Luma 的图生视频流畅自然。

快速易用社媒
🎞️

图生视频（通用玩法）

最稳的工作流

先用图像模型把关键帧画到满意，再喂给视频模型做动态。可控性远高于纯文生视频，是专业首选路径。

推荐流程高可控

视频模型对比

模型画质时长/连贯音频可控性最适合
Sora高强部分中叙事短片
Veo极高强原生高广告 / 写实成片
Runway Gen-4高中部分极高精细可控创作
Kling高强部分高人物 / 性价比
Pika/Luma中中弱中快速概念验证
⚠️ 视频创作的现实预期
视频模型仍有局限：长镜头一致性、手部与文字、复杂物理交互容易出错。专业做法是"分镜化"——把短片拆成多个 3–5 秒镜头分别生成，再用剪辑软件拼接，而不是指望一次生成完整长片。
视频提示词模板（含镜头语言）
[场景/主体]：宇航服猫站在火星沙丘上
[动作]：缓缓抬头望向地平线上升起的地球
[镜头运动]：缓慢推进 (slow dolly-in)，最后定格特写
[氛围/光线]：黄昏暖光，电影感，颗粒质感
[时长/比例]：5s，16:9
（图生视频时，先放入已确定的关键帧图片）
第 6 章 · 模型

🤖Agent 与自动化

Agent 是能"自己调用工具、执行多步骤任务"的 AI。在艺术创作里，它把分散的模型与工具编排成自动化流水线，解放重复劳动。

💬

对话式 Agent（ChatGPT / Claude / Gemini）

通用助手

内置联网、读图、生图、代码执行等能力。可作为创作"指挥中心"：一边聊创意，一边出图、改图、写脚本。

指挥中心多工具
🧱

ComfyUI 工作流

可视化节点编排

艺术创作领域最强的开源自动化工具。把"生图→放大→换脸→生视频"做成节点工作流，一键批量执行，可复用、可分享。

批量自动化可复用
🛠️

通用任务 Agent（Manus 等）

自主多步骤

能自主规划并执行多步骤任务：搜集参考、整理 moodboard、批量调用生成 API、产出交付包。适合复杂项目的"制片助理"。

自主规划多步骤
🔌

API + 脚本 / MCP

深度定制

有开发能力时，可用各模型 API 自建批量生成、自动评分筛选、风格一致性校验等定制流水线，对接公司内部系统。

深度定制可集成

Agent 适合接管哪些工作？

  • 批量生成：同一提示词模板批量产出 100 张备选图，自动筛选高分项。
  • 风格统一：对一批图统一套用 LoRA / 风格参考，保证系列一致性。
  • 多步流水线：生图 → 高清放大 → 抠图 → 合成 → 转视频，全自动串联。
  • 资料整理：自动搜集参考图、生成 moodboard、整理提示词库。
💡 入门建议
团队成员先从对话式 Agent（ChatGPT / Claude）上手，熟悉"对话即创作"。需要批量与精细控制时，再投入学习 ComfyUI——它是当前 AI 美术工业化流程的事实标准。
第 7 章 · 方法

✍️提示词工程

提示词是人与模型之间的"通用语言"。掌握提示词工程，是从"开盲盒"到"精准创作"的分水岭。

1️⃣

结构化优于堆词

按"主体→环境→光线→镜头→风格→参数"的固定结构组织，比随意堆砌关键词更稳定可控。

2️⃣

具体优于抽象

"暖色调"不如"黄昏 4500K 暖光，长投影"；"好看"不如指定具体的艺术家、流派或参考。

3️⃣

善用参考图

图生图、风格参考（sref）、角色参考（cref）比纯文字更能锁定你要的结果。一图胜千词。

4️⃣

负面提示词

在 SD/Flux 中明确排除不想要的元素（多手指、低质、水印），显著提升出图可用率。

提示词要素清单

要素作用示例词
主体画面核心是什么a young woman, ancient dragon, neon city
风格美学方向oil painting, anime, photorealistic, cyberpunk
光线氛围决定项golden hour, rim light, soft studio light
镜头视角与构图wide shot, close-up, low angle, 85mm
画质细节与质感highly detailed, 8k, film grain
参数技术控制--ar 16:9 --style raw --chaos 20
🔧 黄金工作法：让推理模型写提示词
不会写英文提示词？没关系。把你的中文创意 + 目标模型告诉 GPT / Claude，让它产出结构化英文提示词，再粘贴到图像/视频模型里。这是性价比最高的协作模式。

第 9 章 · 实战

🎯实战案例：一条 15 秒品牌概念短片

把前面的知识串起来，走一遍完整流程。目标：为一款虚拟饮品做 15 秒概念短片。

①

构思（推理模型）

用 Claude/GPT 确定调性："未来感 + 自然清新"，产出 3 个分镜脚本，选定一个：产品从星空中坠落→落入森林溪流→特写溅起水花。

②

提示词（推理模型）

让模型为 3 个关键镜头各写一版英文图像提示词 + 视频运动描述，统一风格关键词保证一致性。

③

关键帧（图像模型）

用 Midjourney/Flux 出 3 张关键帧，反复迭代到满意。用 sref 锁定统一视觉风格。

④

动态化（视频模型）

把 3 张关键帧分别用 Kling/Runway 做图生视频，各 5 秒，指定镜头运动。Veo 补一段带音效的镜头。

⑤

合成交付

剪辑软件拼接 3 段，加转场、配乐、字幕。必要时用 Topaz 放大到 4K。导出交付。

⑥

批量变体（Agent）

用 ComfyUI 工作流批量产出不同配色/比例版本（竖版社媒、横版投放），一次成型多平台素材。

⏱️ 效率对比
传统流程：脚本 + 拍摄 + 后期，数天到数周、数万预算。AI 流程：一名熟练创作者半天到一天即可产出可用的概念片，成本骤降——这正是培训的价值所在。
第 10 章 · 规范

⚖️版权与合规（必读）

AI 创作能力越强，越要守住合规底线。以下是团队必须遵守的红线与建议。

🚫 红线
  • 不得直接模仿在世艺术家的署名风格用于商业牟利（"in the style of [在世艺术家]"用于商用有侵权风险）。
  • 不得生成、传播可能侵犯他人肖像权的真实人物形象（尤其是公众人物 / 同事）。
  • 不得将公司机密、未公开素材上传到不可控的第三方模型；敏感项目优先用私有部署模型。
  • 不得生成违法、暴力、色情或误导性内容。
📜

了解授权条款

不同模型的商用授权差异很大。商用前确认所用模型/平台允许商业用途，并保留订阅/授权凭证。

🏷️

标注与溯源

对外交付时按平台/客户要求标注"AI 生成"。保留提示词、版本记录，便于追溯与复现。

🔒

数据安全

涉密素材使用私有/本地模型；关闭第三方平台的"训练数据收集"选项（如有）。
