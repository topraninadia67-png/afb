# 三亚千古情艺术团 · 管理小程序

面向**三亚千古情艺术团**团员日常管理的微信小程序（微信小程序 + 云开发，无需自建服务器）。

## ✨ 功能

| 功能 | 团员 | 管理员 |
|------|------|--------|
| 📋 **日常检查汇总** | 按区域填报每日检查（消防/卫生/安全等），可看自己历史 | 查看全部团员的检查记录，可筛选异常 |
| 📖 **制度查询** | 关键词智能检索各项制度条款 | 增删制度内容 |
| ➖ **扣分查询** | 查看本人扣分记录与累计 | 录入 / 删除扣分 |
| 🎓 **安全培训 + 随机出题** | 学习培训资料，随机抽题考试、云端判分、错题解析 | 查看全部成绩，管理题库 |
| ✉️ **匿名意见箱** | 完全匿名提交意见建议 | 查看 / 处理全部意见 |

**权限设计**：普通团员填姓名即用，只能看自己的数据；管理员凭专属密码进入后台，统一查看所有汇总、意见箱、考试成绩。管理员密码在云端哈希校验，不写入前端代码。

## 🗂 项目结构

```
miniprogram/            小程序前端
  app.js / app.json     入口与全局配置（云环境 ID 在 app.js）
  pages/
    index/              首页（身份 + 功能入口）
    daily/              日常检查填报与历史
    rules/              制度查询
    deduction/          扣分查询
    training/           培训资料
    exam/               随机出题考试
    suggestion/         匿名意见箱
    admin/              管理员后台
  utils/api.js          云函数调用封装
cloudfunctions/         云开发后端
  init/                 初始化（建库 + 示例制度/题库/培训 + 管理员密码）
  member/               团员业务（填报/查询/出题/判分/匿名意见）
  admin/                管理员业务（登录鉴权 + 汇总/成绩/意见/扣分/内容管理）
部署指南.md             ⭐ 完整上线步骤，请先阅读
```

## 🚀 快速开始

详见 **[部署指南.md](部署指南.md)**。概要：

1. 注册微信小程序账号，拿到 AppID。
2. 用微信开发者工具导入本项目，开通云开发。
3. 把云环境 ID 填入 `miniprogram/app.js`。
4. 上传部署 `init` / `member` / `admin` 三个云函数。
5. 运行一次 `init` 初始化数据（设管理员密码）。
6. 设置数据库集合权限（保护匿名意见与隐私）。
7. 预览 → 上传 → 提交审核 → 发布。

## 📝 替换真实内容

示例制度与题库在 `cloudfunctions/init/seed.js`，也可直接在 App「管理员后台 → 内容管理」增删。把真实制度文件与安全培训题目发来即可批量整理。
